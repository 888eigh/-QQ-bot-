========================================
  QQ Bot 本地运行指南
========================================

【环境要求】
- Windows 10/11
- Python 3.10 或更高版本
- 下载地址: https://www.python.org/downloads/
- 安装时务必勾选 "Add Python to PATH"

【快速开始】

第1步：安装 Python
  下载并安装 Python，安装时勾选 "Add Python to PATH"

第2步：启动 Bot
  双击运行 start.bat
  （首次运行会自动安装依赖，需要几分钟）

第3步：配置 NapCat
  打开 NapCat 目录下的 config/onebot11_<你的QQ号>.json
  找到 websocketClients，修改为：

  "websocketClients": [
    {
      "enable": true,
      "url": "ws://127.0.0.1:8081/onebot/v11/ws"
    }
  ]

  保存后重启 NapCat

第4步：测试
  用另一个QQ给Bot QQ发消息：
  - 发 "你好" → AI回复
  - 发 "/help" → 查看指令
  - 发 "/ping" → 测试连通

【每小时报告推送】
  双击运行 start_report.bat
  每小时整点自动发送运行报告到 backedcmd@163.com
  （需要保持该窗口开启）

【配置说明】

config/config.json - 主配置文件
  - api_key: DeepSeek API密钥（已配置）
  - bot_port: Bot监听端口（默认8081）
  - superusers: 管理员QQ号（已配置365048565）
  - chat_system_prompt: AI性格设定

config/report_config.json - 报告推送配置
  - sender: 发件邮箱（backedcmd@163.com）
  - password: 邮箱授权码（已配置）
  - receiver: 收件邮箱

【功能指令】

普通指令：
  /help     - 查看帮助
  /ping     - 测试Bot是否在线
  /docs     - 查看文档指令列表
  /personality - 查看/设置AI性格
  /affinity    - 查看好感度

文档指令（可自定义）：
  在 text/ 目录下添加 .txt 文件
  文件名即指令名，如 text/hello.txt
  用户发 /hello 会回复文件内容

图片/表情：
  picture/   - 存放图片，AI可选择发送
  emotional/ - 存放表情，AI可选择发送

随机消息：
  boring.txt - 每句话用%分隔
  Bot会不定时随机发送其中一句话

【日志文件】
  logs/ 目录下：
  - bot_YYYY-MM-DD.log   - 运行日志
  - error_YYYY-MM-DD.log - 错误日志
  - api_YYYY-MM-DD.log   - API调用日志
  全部使用 UTF-8 编码

【常见问题】

Q: 启动提示 "No module named 'nonebot'"
A: 依赖未安装，运行 pip install -r requirements.txt

Q: NapCat 连接失败
A: 检查Bot是否启动，确认端口号一致（默认8081）

Q: AI不回复
A: 检查API密钥是否正确，查看logs/api_*.log

Q: 邮件收不到
A: 检查163邮箱SMTP是否开启，授权码是否正确

【技术支持】
  查看 logs/ 目录下的错误日志
  或运行 python bot.py 查看控制台输出
