# -QQ-bot-
<p>写在前面
<p>注意：1.本仓库不包含napcat架构文件和QQ安装包，需使用请自行下载
<p>2.使用前请确保python环境为3.1.2+
<p>3.代码运行需要nonebot，nonebot-adapter-onebot，websockets等，可自行查看头文件需要的运行库
<p>4.项目文件夹下的多媒体资源需自行添加picture 文件夹的图片和 emotional 文件夹下的表情
<p>5.文件夹下的boring.txt是用来添加随机话语的，每句话请用%分隔
<p>GUI功能如下
<p>功能模板页：欢迎语、群规、关于、帮助、AI 人设、自定义指令，填空式生成
<p>高级设置页：API 配置、Bot 配置、NapCat 配置、日志配置、聊天配置，所有参数可改
<p>其余可自行配置
<p>项目文件下的exe.bat可一键打包程序为exe文件
